# 拗口术语替换表

**目的**: 让术语更好说、更好记  
**更新日期**: 2026-11-23

---

## 🎯 替换原则

1. **长变短** - 5个字 → 2-3个字
2. **拗口变顺口** - 难念 → 好念
3. **技术变通俗** - 专业 → 白话
4. **保留英文备注** - 括号内标注

---

## 📋 核心术语简化

### 7个原语

| 拗口版本 | 简化版本 | 通俗说法 | 使用建议 |
|---------|---------|---------|---------|
| 更高的高点 | 更高高点 / HH | 新高 | ✅ 文档用"更高高点(HH)" |
| 更高的低点 | 更高低点 / HL | 高位回调 | ✅ 口语用"创新高" |
| 更低的低点 | 更低低点 / LL | 新低 | ✅ 图解用"HH↑" |

## 📖 文档写作示例

### ❌ 拗口版本

```
当检测到价格产生了一个更高的高点(HH)时，
系统将new_count进行自增操作，
同时将no_new_span重置为0。
如果当前波段的守护点被价格击穿，
则life_state将转换为broken状态。
```

### ✅ 简化版本

```
当创新高(HH)时，
创新次数+1，
停滞时长归零。
如果破位了，
状态变为终止(broken)。
```

### ✅ 通俗版本

```
涨到新高度时，
记一次创新高，
停滞计数清零。
跌破关键位置时，
这波就算走完了。
```

## 💡 使用建议

### 分场景使用

**正式文档** → 使用标准术语
```
"当出现更高高点(HH)时，新值计数(new_count)增加"
```

**团队讨论** → 使用简化术语
```
"创新高了，记一次"
```

**对外讲解** → 使用通俗术语
```
"涨到新高度，记一笔"
```

**代码注释** → 中英结合
```python
# 检查HH(更高高点/新高)
if is_new_high:
    new_count += 1  # 创新次数+1
```
