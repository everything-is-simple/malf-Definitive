## 🏗️ 完整概念（12个）

### Mini的10个（继承）

1-10: HH/HL/LL/LH/break/new-count/no-new-span/alive/broken/reborn

### Plus新增的2个

**11. update_rank（更新位置）**

**定义**: 当前new_count在历史中的分位

**公式**:
```python
update_rank = count(历史i.new_count < 当前new_count) / N
```

**含义**:
- 0.2 = 比历史20%的波段创新次数少
- 0.5 = 中位数
- 0.8 = 比历史80%的波段创新次数多

**用途**: 判断当前波段的生长程度

---

**12. stagnation_rank（停滞位置）**

**定义**: 当前no_new_span在历史中的分位

**公式**:
```python
stagnation_rank = count(历史i.no_new_span < 当前no_new_span) / N
```

**含义**:
- 0.2 = 停滞较短
- 0.5 = 中位数
- 0.8 = 停滞较长

**用途**: 判断当前波段的停滞程度

## ⚙️ 完整功能（5个）

### Mini的3个（继承）

功能1-3: 推进守护+寿命呼吸+状态转移

### Plus新增的2个

**功能4: 样本池管理**

**样本池key**:
```python
pool_key = (symbol, timeframe, direction)

示例:
- ("000001", "日线", "UP")   ← 独立池
- ("000001", "周线", "UP")   ← 独立池（级别不同）
- ("000001", "日线", "DOWN") ← 独立池（方向不同）
```

**入池规则**:
```python
if life_state == "broken":
    # 波段终止，可以入池
    历史池[pool_key].add({
        "new_count": 终止时的new_count,
        "no_new_span": 终止时的no_new_span,
        "终止时间": timestamp
    })
```

**三维不混**:
- 同股（symbol）
- 同级别（timeframe）
- 同方向（direction）

---

**功能5: 分位计算**

**算法**:
```python
def 计算分位(当前值: int, 历史值列表: List[int]) -> float:
    """严格小于"""
    if len(历史值列表) < 30:
        return None  # 样本不足
    
    小于当前的数量 = sum(1 for v in 历史值列表 if v < 当前值)
    return 小于当前的数量 / len(历史值列表)

# 使用
update_rank = 计算分位(当前new_count, 历史new_count列表)
stagnation_rank = 计算分位(当前no_new_span, 历史no_new_span列表)
```

**规则**:
- 严格小于（`<` 不是 `<=`）
- 样本门槛: N ≥ 30
- 防前视: 只用历史数据
- 值域: [0, 1)

## 🎯 增强输出

### WavePosition（6字段）

```python
@dataclass
class WavePosition:
    """Plus版输出"""
    
    # Mini的4个字段
    direction: Literal["UP", "DOWN"]
    new_count: int
    no_new_span: int
    life_state: Literal["alive", "broken", "reborn"]
    
    # Plus新增的2个字段
    update_rank: float | None      # 更新位置
    stagnation_rank: float | None  # 停滞位置
```

**示例**:
```python
wp = WavePosition(
    direction="UP",
    new_count=5,
    no_new_span=9,
    life_state="alive",
    update_rank=0.75,      # 比历史75%波段创新次数多
    stagnation_rank=0.60   # 比历史60%波段停滞长
)

# 解读：
# 上升波，创新高5次（历史上位25%），
# 当前停滞9天（历史中上位40%），
# 波段仍活着
```

### 分位计算优化

```python
# 朴素算法: O(N)
def 计算分位_朴素(当前值, 历史列表):
    return sum(1 for v in 历史列表 if v < 当前值) / len(历史列表)

# 优化: 预排序 + 二分查找 O(logN)
import bisect

历史列表_排序 = sorted(历史列表)
位置 = bisect.bisect_left(历史列表_排序, 当前值)
rank = 位置 / len(历史列表)
```

if update_rank > 0.8 and stagnation_rank > 0.7:

## 📊 四象限分类

```
stagnation_rank
     ▲
     │
  高 │  弱生停滞区  │  成熟停滞区
     │  低更新+高停滞│  高更新+高停滞
0.5  ├──────────────┼──────────────► update_rank
     │  初生推进区  │  成熟推进区
  低 │  低更新+低停滞│  高更新+低停滞
     │

四区：
1. 初生推进区（左下）：刚起步，活跃
2. 成熟推进区（右下）：已长成，仍推进
3. 成熟停滞区（右上）：已走远，停滞久
4. 弱生停滞区（左上）：未长成，已停久
```
