## 📊 数据结构

### 核心状态（WaveState）

```python
@dataclass
class WaveState:
    """内部状态追踪（不对外暴露）"""
    
    # 当前极值
    current_high: float
    current_low: float
    
    # 守护点（当前有效）
    guard_high: float | None  # 下降波的LH
    guard_low: float | None   # 上升波的HL
    
    # 寿命
    new_count: int = 0
    no_new_span: int = 0
    life_state: Literal["alive", "broken", "reborn"] = "alive"
    
    # 方向
    direction: Literal["UP", "DOWN"] | None = None
    
    # 辅助字段（可选）
    birth_bar: int = 0  # 诞生时的bar序号
```

**说明**:
- `current_high/low`: 当前波段的最高/最低价
- `guard_high/low`: 守护点（v1.3精确：current_effective_guard）
- `new_count`: 创新高/低的次数
- `no_new_span`: 未创新高/低的周期数
- `life_state`: alive/broken/reborn
- `direction`: UP/DOWN

---

### 输出结构（WavePosition）

```python
@dataclass
class WavePosition:
    """对外输出（不可变）"""
    
    direction: Literal["UP", "DOWN"]
    new_count: int
    no_new_span: int
    life_state: Literal["alive", "broken", "reborn"]
    
    def __str__(self) -> str:
        return f"WavePosition({self.direction}, " \
               f"推进{self.new_count}次, " \
               f"停滞{self.no_new_span}期, " \
               f"{self.life_state})"
```

## 🔧 核心算法

### 主循环（on_bar）

```python
def on_bar(state: WaveState, bar: PriceBar) -> WavePosition:
    """
    每根K线调用一次
    
    Args:
        state: 当前状态（会被修改）
        bar: 当前K线 (open, high, low, close)
        
    Returns:
        WavePosition: 当前波段位置
    """
    
    # 1. 检查推进（HH/LL）
    进行推进检查(state, bar)
    
    # 2. 检查守护破坏（break）
    检查守护破坏(state, bar)
    
    # 3. 检查重生（reborn）
    检查重生(state, bar)
    
    # 4. 更新停滞
    更新停滞计数(state)
    
    # 5. 输出
    return WavePosition(
        direction=state.direction,
        new_count=state.new_count,
        no_new_span=state.no_new_span,
        life_state=state.life_state
    )
```

---

### 算法1: 推进检查

```python
def 进行推进检查(state: WaveState, bar: PriceBar) -> None:
    """检查HH/LL"""
    
    if state.direction == "UP":
        # 上升波：检查HH
        if bar.high > state.current_high:
            # HH出现
            state.current_high = bar.high
            state.new_count += 1
            state.no_new_span = 0
            
    elif state.direction == "DOWN":
        # 下降波：检查LL
        if bar.low < state.current_low:
            # LL出现
            state.current_low = bar.low
            state.new_count += 1
            state.no_new_span = 0
```

**关键**:
- HH: `bar.high > current_high`
- LL: `bar.low < current_low`
- 推进时: `new_count+1`, `no_new_span=0`

---

### 算法2: 守护破坏检查

```python
def 检查守护破坏(state: WaveState, bar: PriceBar) -> None:
    """检查break"""
    
    if state.life_state != "alive":
        return  # 只在alive时检查
    
    if state.direction == "UP":
        # 上升波：检查HL被破
        if state.guard_low is not None:
            if bar.low < state.guard_low:
                # break!
                state.life_state = "broken"
                
    elif state.direction == "DOWN":
        # 下降波：检查LH被破
        if state.guard_high is not None:
            if bar.high > state.guard_high:
                # break!
                state.life_state = "broken"
```

**关键**:
- 上升波break: `bar.low < guard_low`
- 下降波break: `bar.high > guard_high`
- break时: `life_state = "broken"`

---

### 算法3: 重生检查

```python
def 检查重生(state: WaveState, bar: PriceBar) -> None:
    """检查reborn"""
    
    if state.life_state != "broken":
        return  # 只在broken时检查
    
    # 检查新方向首个极值
    # 简化：任何HH/LL都算重生
    if 出现HH(bar) or 出现LL(bar):
        state.life_state = "reborn"
        
        # 重置寿命
        state.new_count = 0
        state.no_new_span = 0
        
        # 确定新方向
        if 出现HH(bar):
            state.direction = "UP"
            state.current_high = bar.high
            state.guard_low = bar.low
        else:
            state.direction = "DOWN"
            state.current_low = bar.low
            state.guard_high = bar.high
```

**关键**:
- broken后等待新极值
- 新极值出现 → reborn
- 重置寿命，确定新方向

---

### 算法4: 停滞更新

```python
def 更新停滞计数(state: WaveState) -> None:
    """每个周期检查"""
    
    if state.life_state != "alive":
        return  # 只在alive时累积
    
    # 如果本周期没推进，停滞+1
    # （推进时已经归零，这里只处理未推进的情况）
    if 本周期未推进:
        state.no_new_span += 1
```

**关键**:
- 只在alive时累积
- 推进时已归零
- 未推进时累积

## 🔄 守护点更新逻辑

### 上升波守护点（HL）

```python
def 更新上升守护点(state: WaveState, bar: PriceBar) -> None:
    """更新HL守护点"""
    
    # 在回调时更新
    if bar.low > state.guard_low:
        # HL抬高了
        state.guard_low = bar.low
```

### 下降波守护点（LH）

```python
def 更新下降守护点(state: WaveState, bar: PriceBar) -> None:
    """更新LH守护点"""
    
    # 在反弹时更新
    if bar.high < state.guard_high:
        # LH降低了
        state.guard_high = bar.high
```

## 📐 完整状态转移表

| 当前状态 | 触发条件 | 新状态 | 操作 |
|---------|---------|--------|------|
| **alive** | HH/LL出现 | alive | new_count+1, no_new=0 |
| **alive** | 无新极值 | alive | no_new+1 |
| **alive** | 破守护点 | broken | 记录破位 |
| **broken** | 新极值出现 | reborn | 重置寿命 |
| **reborn** | 自动 | alive | 进入新生命 |
