## 🏗️ 核心概念（10个）

### 一、7个原语 (Primitives)

| # | 中文 | 英文 | 简写 | 含义 | 职责 |
|---|------|------|------|------|------|
| 1 | 更高高点 | Higher High | HH | 价格创新高 | **推进**（上升） |
| 2 | 更高低点 | Higher Low | HL | 回调不破前低 | **守护**（上升） |
| 3 | 更低低点 | Lower Low | LL | 价格创新低 | **推进**（下降） |
| 4 | 更低高点 | Lower High | LH | 反弹不破前高 | **守护**（下降） |
| 5 | 结构破坏 | Break | - | 守护点被击穿 | **转移触发** |
| 6 | 新值计数 | New Count | - | 创新高/低次数 | **生长指标** |
| 7 | 停滞跨度 | No-New Span | - | 未创新高/低周期数 | **停滞指标** |

**职责分离**:
```
HH/LL → 推进 (创造趋势与空间)
HL/LH → 守护 (维持结构与节奏)
break → 转移 (结构被破，状态切换)
```

---

### 二、3个状态 (States)

| # | 中文 | 英文 | 含义 | 触发条件 |
|---|------|------|------|---------|
| 8 | 活着 | alive | 结构存活中 | 守护点未破 |
| 9 | 终止 | broken | 结构已破坏 | 守护点被击穿 |
| 10 | 重生 | reborn | 新方向建立 | 新方向首个极值 |

**关键原则**: **break ≠ confirmation**
- break: 守护点被破（终止触发）
- confirmation: 新方向首个HH/LL（重生确认）

## ⚙️ 核心功能（3个）

### 功能1: 推进×守护机制

**上升结构**:
```
推进: HH → HH → HH (不断创新高)
      ↑     ↑     ↑
守护: HL    HL    HL (回调不破低)
      │
      └─ 一旦HL被破 → break → 结构终止
```

**下降结构**:
```
推进: LL → LL → LL (不断创新低)
      ↓     ↓     ↓
守护: LH    LH    LH (反弹不破高)
      │
      └─ 一旦LH被破 → break → 结构终止
```

**规则**:
- HH/LL负责推进
- HL/LH负责守护
- 一段波 = 推进在守护内延续

---

### 功能2: 寿命呼吸

**生长记录**: new-count
```python
if 出现HH:  # 上升波
    new_count += 1
    no_new_span = 0
elif 出现LL:  # 下降波
    new_count += 1
    no_new_span = 0
```

**停滞记录**: no-new-span
```python
else:  # 本周期无新高/新低
    # new_count 不变
    no_new_span += 1
```

**寿命呼吸**:
```
价格 ▲
     │  HH    停滞   HH    停滞   HH
     │   │     ↓↓↓    │     ↓↓↓    │
     ├───HL───────────HL───────────HL────► 时间
         │            │            │
    new_count=1  new_count=2  new_count=3
    no_new=0     no_new累积   no_new=0

推进与停滞交替 = 寿命呼吸
波段不是直线前进，而是在推进-停滞间呼吸
```

---

### 功能3: 状态转移

**状态机**:
```
alive (活着)
  │
  ├─ HH/LL出现 → new_count+1, no_new=0 (推进)
  ├─ 无新高/低 → no_new+1 (停滞)
  └─ break守护点 → broken (终止)
       │
       └─ 新方向HH/LL → reborn (重生)
            │
            └─ 延续 → alive (新生命)
```

**转移规则**:
```python
# alive → broken
if 上升波 and 价格 < current_effective_HL:
    life_state = "broken"
elif 下降波 and 价格 > current_effective_LH:
    life_state = "broken"

# broken → reborn
if 新方向首个HH or 新方向首个LL:
    life_state = "reborn"

# reborn → alive
if 新方向延续:
    life_state = "alive"
```

## 🎯 核心输出

### WavePosition (波段位置)

```python
@dataclass
class WavePosition:
    """波段位置（中文：波段位置 | 英文：Wave Position）"""
    
    # 方向 (Direction)
    direction: Literal["UP", "DOWN"]
    # UP = 上升波 | DOWN = 下降波
    
    # 新值计数 (New Count)
    new_count: int
    # 创新高/低的次数，记录生长
    
    # 停滞跨度 (No-New Span)
    no_new_span: int
    # 未创新高/低的周期数，记录停滞
    
    # 寿命状态 (Life State)
    life_state: Literal["alive", "broken", "reborn"]
    # alive=活着 | broken=终止 | reborn=重生
```

**示例**:
```python
wp = WavePosition(
    direction="UP",
    new_count=5,
    no_new_span=9,
    life_state="alive"
)

# 解读：
# 上升波，已创新高5次，当前停滞9个周期，仍活着
```

## 🔧 实现要点

### 最小状态追踪

```python
class WaveState:
    """最小状态（内部使用）"""
    
    # 当前极值
    current_high: float
    current_low: float
    
    # 守护点
    guard_high: float | None  # 下降波的LH
    guard_low: float | None   # 上升波的HL
    
    # 寿命
    new_count: int = 0
    no_new_span: int = 0
    life_state: str = "alive"
    direction: str | None = None
```

### 核心循环

```python
def on_bar(state: WaveState, bar: PriceBar) -> WavePosition:
    """每根K线调用一次"""
    
    # 1. 检查推进（HH/LL）
    if 出现新高/新低:
        state.new_count += 1
        state.no_new_span = 0
    else:
        state.no_new_span += 1
    
    # 2. 检查守护破坏（break）
    if 守护点被破:
        state.life_state = "broken"
    
    # 3. 检查重生（reborn）
    if 新方向首个极值:
        state.life_state = "reborn"
    
    # 4. 输出
    return WavePosition(
        direction=state.direction,
        new_count=state.new_count,
        no_new_span=state.no_new_span,
        life_state=state.life_state
    )
```
