# 推进守护图

**图解**: HH/LL推进，HL/LH守护，break转移  
**更新日期**: 2026-11-23

---

## 🎯 核心概念

**职责分离**:
- **HH/LL** → 推进（创造趋势与空间）
- **HL/LH** → 守护（维持结构与节奏）
- **break** → 转移（结构被破，状态切换）

---

## 📈 上升结构：推进×守护

### 完整示意图

```
价格 ▲
     │
 HH3 │                     ●  ← 第3次推进
     │                    /
 HH2 │              ●    /   ← 第2次推进
     │             /│   /
 HH1 │       ●    / │  /     ← 第1次推进
     │      /│   /  │ /
  H0 │    ● │  /   │/        ← 起点
     │   /  │ /    /
 HL1 │  /   ●     /          ← 第1次守护（回调不破）
     │ /   /│    /
 HL2 │/   / │   ●            ← 第2次守护（回调不破）
     │   /  │  /│
     │  /   │ / │
     │ /    │/  │
     │/     /   │
     └──────────────────────► 时间

推进线（HH）: H0 → HH1 → HH2 → HH3
守护线（HL）: HL1 → HL2 (逐步抬高)

一旦价格跌破当前HL → break → 上升结构终止
```

---

### 推进者：HH（更高高点）

**作用**: 创造趋势与空间

```
价格 ▲
     │
 HH2 │       ●  ← 创新高！推进成功
     │      /│
 HH1 │    ●  │  ← 前高
     │   /│  │
  H0 │  ● │  │  ← 起点
     │    │  │
     └────┴──┴────► 时间

HH出现时:
  - new_count + 1    (记录推进)
  - no_new_span = 0  (停滞归零)
  - 趋势空间扩大
```

**特征**:
- 价格突破前高
- 创造新的高度
- 推动趋势前进

---

### 守护者：HL（更高低点）

**作用**: 维持结构与节奏

```
价格 ▲
     │
 HH1 │    ●          ← 推进到这里
     │   /│\
     │  / │ \
  H0 │ ●  │  \       ← 起点
     │    │   \回调
     │    │    \
 HL1 │    ●─────●    ← 守护点：不破！
     │
     └────────────► 时间

HL的作用:
  - 回调不破前低
  - 保护上升结构
  - 一旦被破 → break
```

**特征**:
- 低点逐步抬高
- 形成支撑
- 守护趋势完整性

---

### 破坏者：break

**触发**: 价格跌破当前HL

```
价格 ▲
     │
 HH2 │       ●
     │      /│\
     │     / │ \
 HH1 │   ●   │  \
     │  /│   │   \
  H0 │ ● │   │    \
     │   │   │     \
 HL1 │   ●═══●      ● ← 守护线
     │       │      │\
     │       │      │ ↓ 跌破！
     │       │      ×  ← break点
     │       │     /│
     │       │    / │
     └───────┴───┴──┴────► 时间

break发生:
  - 上升结构终止
  - 进入broken状态
  - 等待新方向确认
```

## 🎨 推进守护循环

### 上升波的完整循环

```
起点(H0)
  ↓
推进: HH1出现 → new_count=1
  ↓
回调: 形成HL1 → 守护建立
  ↓
推进: HH2出现 → new_count=2
  ↓
回调: 形成HL2 → 守护更新
  ↓

  ↓

  ↓
结构终止
```

```
  ↓

  ↓
反弹: 形成LH2 → 守护更新
  ↓
推进: LL3出现 → new_count=3
  ↓
反弹: 涨破LH2 → break!
  ↓
结构终止
```

## 🔑 守护点的关键特性

### 特性1: 动态更新

```
上升波守护点变化:
HL1 = 100 → 守护点
  ↓ HH出现，回调
HL2 = 110 → 新守护点（抬高了）
  ↓ HH出现，回调
HL3 = 115 → 新守护点（再抬高）

守护点逐步抬高 = 结构健康
```

---

### 特性2: 当前有效守护点

```
上升波历史:
HL1 = 100
HL2 = 110
HL3 = 115 ← 当前有效守护点

只有HL3被破才算break
HL1/HL2已失效
```

**关键**: current_effective_guard（v1.3精确化）

---

### 特性3: 守护点失效

```
情况1: 被更新守护点替代
HL1 = 100 → HL2 = 110出现 → HL1失效

情况2: 被break击穿
价格跌破HL2 → HL2守护失败 → 结构终止

情况3: 推进过多后自然失效
HH出现多次后，早期HL已太远，自然失效
```

## 📊 推进守护强度分析

### 推进强度

**强推进**:
```
HH频繁出现
HH1 → HH2 → HH3 → HH4
间隔: 1-2天

特征: 推进快，动能强
```

**弱推进**:
```
HH偶尔出现
HH1 → (停10天) → HH2 → (停15天) → HH3
间隔: 10+天

特征: 推进慢，动能弱
```

---

### 守护强度

**强守护**:
```
HL逐步抬高
HL1=100 → HL2=110 → HL3=120
每次+10

特征: 守护强，支撑好
```

**弱守护**:
```
HL抬升缓慢
HL1=100 → HL2=102 → HL3=103
每次+2

特征: 守护弱，易破
```

## 🎯 实战识别

### 识别推进

```python
# 上升波
if bar.high > current_high:
    is_HH = True
    new_count += 1
    
# 下降波
if bar.low < current_low:
    is_LL = True
    new_count += 1
```

---

### 识别守护

```python
# 上升波守护点
if 回调后:
    if bar.low > previous_low:
        is_HL = True
        guard_low = bar.low  # 更新守护点
        
# 下降波守护点
if 反弹后:
    if bar.high < previous_high:
        is_LH = True
        guard_high = bar.high  # 更新守护点
```

---

### 识别break

```python
# 上升波break
if bar.low < guard_low:
    is_break = True
    life_state = "broken"
    
# 下降波break
if bar.high > guard_high:
    is_break = True
    life_state = "broken"
```
