## 🔧 术语速查

| 中文 | 英文 | 简写 | 含义 |
|------|------|------|------|
| 更高高点 | Higher High | HH | 推进（上升） |
| 更高低点 | Higher Low | HL | 守护（上升） |
| 更低低点 | Lower Low | LL | 推进（下降） |
| 更低高点 | Lower High | LH | 守护（下降） |
| 结构破坏 | Break | - | 状态转移触发 |
| 新值计数 | New Count | - | 生长指标 |
| 停滞跨度 | No-New Span | - | 停滞指标 |
| 波段位置 | Wave Position | WP | 核心输出 |

- 不写具体代码
